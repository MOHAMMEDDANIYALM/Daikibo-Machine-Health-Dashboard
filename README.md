# Daikibo Factory Machine Health Dashboard

This repository contains the development files for a private dashboard monitoring the health status of machines across Daikibo's factories.

## Contents
- **Proposal**: A formal document outlining the project scope, timeline, and support.
- **Dashboard.pbix**: The Power BI dashboard file.
- **SampleData**: Example telemetry data used in the dashboard.
- **Screenshots**: Images of the dashboard for reference.

## Description
The dashboard provides:
- Real-time machine health status for 4 factories (9 machines each)
- Collapsible views by factory and machine
- Historical telemetry trends
- Access restricted to internal users (authentication synced to internal server)

## Usage
1. Open `Dashboard.pbix` in Power BI Desktop.
2. Connect to telemetry data .
3. Explore factory and machine statuses.
